# P2 实验协议（运行 MAC-VO 结果之前固定）

输入采用 MAC-VO 官方 README 指向的双目演示序列，实测1274帧，640×480，官方适配器 K=(320,320,320,240)、baseline=0.25m。第一组固定使用前200帧、stride=1，不按测试误差挑选片段。GT pose、GT depth、GT flow 不进入在线模型；演示没有IMU和Wheel，不虚构补全。

已实测 SGBM + 双向LK + EPNP-RANSAC + LM 常规双目VO，作为B1工程基线。这是明示参数的常规方法，不冒称已复现另一篇论文。默认参数在代码中保存，不按MAC-VO成绩调优。

MAC-VO 使用官方网络、官方两帧优化器、官方权重与固定git/submodule版本。先记录BF16原精度配置在本机的真实行为；GTX1660不支持BF16时，使用明确标记的全FP32 encoder/decoder变体（FP16 encoder在本机产生无效观测）。关闭dense mapping（保留配置中未调用的mappoint selector），保持两帧VO跟踪缓存，不改变已有只读先验地图。关闭GT观测，禁止使用GT motion model。

不确定性路线分两层：

- 官方模型生成像素/视差方差，MatchCovariance公式生成米制3×3观测协方差。公式已用独立高斯输入的蒙特卡洛二阶矩验证。它不是位姿协方差。
- Fast版本的优化图实际采用pixel+disparity残差；权重消融仅将该残差的协方差矩阵改为单位阵，保留相同网络、关键点选择、观测过滤、初值和鲁棒核。不能把此组称为整套不确定性全部关闭，也不能把像素方差与米制方差混同。

评价包括：SE3对齐ATE（不校正尺度）、仅首位姿对齐ATE、1/5/10帧RPE、终点漂移/真实路程、原始lost标志与最长连续失败帧数、实测延迟、显存。原始轨迹与官方插值轨迹分别保留；插值不被算作恢复了跟踪可用率。缺少真实时间戳时不报告失败秒数或物理采样率。

原加载器在缺少cam_time.npy时假定10Hz；协议明确该序列只有帧索引可验证，不能拿这个假定时间融合IMU/Wheel。正式三传感器实验改用实际下载和解码的OpenLORIS；其GT和LiDAR在定位器输入中严格排除。

算法失败必须写failure.json并返回非零退出状态；不能因官方上层receive_frames捕获异常后继续结束，就把程序退出当作实验成功。只有所需全部帧、轨迹文件、逐帧记录与离线指标同时存在，才能计为完成。

消融实施审计：主进程monkeypatch未传入spawn优化子进程，首次identity运行无效，完整保留INVALID_ABLATION.json。有效消融改为固定38,404条实际学习匹配的官方后端顺序重放；求解器内部逐次断言权重为单位阵/非单位阵并记录调用次数。以加权重放与原端到端轨迹的差异验证重放一致性。
