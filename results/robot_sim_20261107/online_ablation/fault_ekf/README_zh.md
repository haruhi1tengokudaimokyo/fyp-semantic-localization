# 同一故障记录的 Wheel/IMU EKF 消融

在独立 ROS domain 75，以真实墙钟 1× 速度重放 `online_fault/capture` 的原始传感器：26,815 条轮关节状态、5,988 条 IMU、533 对双目图像，输入时间覆盖 60.276 秒。没有启动 GPU 模型，没有启动 Gazebo 或发布控制指令，没有向估计器提供 GT 或绑架事件标签。两个子进程均正常退出；所有原始记录均发布成功，调度延迟 P95 为 2.11 ms。

发布成功不等于所有 ROS 订阅回调均收到：估计器实际记录 26,808 条轮速、5,988 条 IMU、516 条相机消息，生成 1,801 次局部位姿。缺失回调按实保留，未补造样本；比较不同回放时应同时检查各自收发计数。EKF 配置不使用相机消息更新状态。

独立离线评价含 533 帧。此配置没有地图绝对定位源，因此全局覆盖为 0；这不是“0 米误差”，也不能通过 GT 初始化伪造全局输出。可评价的局部里程计为 523 帧，覆盖 98.12%，仅用于诊断的首帧原点对齐平移 RMSE 为 1.4483 m，中位数为 0.0430 m。

故障记录包含图像接口人工黑屏和 Gazebo 位姿绑架，不是自然遮挡。黑屏期间局部里程计覆盖 98.36%；真实跳变在仿真时间 41.1 秒发生（平移 2.3169 m），EKF 未恢复地图定位，恢复事件按观察窗口结束记为右删失。纯轮速/IMU不能检测静止外搬造成的全局位置变化；这一消融为同输入 ACE/融合实验提供基线。

完整逐帧原始输出及离线误差位于 `/home/csy/Documents/Codex/2026-10-31/new-chat/outputs/RobotSim_20261107/ablation_fault_ekf`。此实验是已有真实模拟传感器的在线时序回放，不是第二次运行物理场景，也不证明真实机器人可靠性。没有依照查询 GT 调整阈值或参数。
